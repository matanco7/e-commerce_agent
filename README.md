Conversational Agent that can handle customer support queries for an e-commerce platform.

The chatbot function-calling based and can handle multi-turn conversations and provide customer inquiries about order status, return policies and more.

Functionalities:
1. Answer user's query regerding order_id @ files/orders.csv
2. When user is asking for human representative, the bot saves the user's info @ files/contacts.csv
3. The bot can tell the platform's return policies.
